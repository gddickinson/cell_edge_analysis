┌─ LAUNCHING ────────────────────────────────────────────────────┐
│ python launch_gui.py                                           │
│ or: python cell_edge_analysis_gui.py                          │
└────────────────────────────────────────────────────────────────┘

┌─ WORKFLOW ─────────────────────────────────────────────────────┐
│ 1. Setup & Run Tab:                                            │
│    ├─ Browse → Select Image Stack (PIEZO1)                    │
│    ├─ Browse → Select Mask Stack                              │
│    ├─ Configure parameters (or use defaults)                  │
│    └─ Run All Steps (or Run Selected Step)                    │
│                                                                 │
│ 2. Results Viewer Tab:                                         │
│    ├─ Select view type from dropdown                          │
│    ├─ Navigate: ◄◄ ◄ ► ►►                                    │
│    └─ Update View to refresh                                  │
│                                                                 │
│ 3. Statistics Tab:                                             │
│    └─ Review comprehensive analysis statistics                │
└────────────────────────────────────────────────────────────────┘

┌─ KEY PARAMETERS ───────────────────────────────────────────────┐
│                                                                 │
│ STEP 1 - Data Loading                                          │
│   • Normalize Frames: ON (recommended)                         │
│   • Normalization Scale: 100.0                                 │
│   • Subtract Background: ON (recommended)                      │
│   • Background Percentile: 10.0                                │
│                                                                 │
│ STEP 2 - Edge Detection                                        │
│   • Smooth Edges: ON (recommended)                             │
│   • Smoothing Sigma: 20.0 (range: 10-40)                      │
│     └─ Increase for noisy edges (30-40)                       │
│     └─ Decrease for fine features (10-15)                     │
│                                                                 │
│ STEP 3 - Displacement                                          │
│   • Min Movement Pixels: 5                                     │
│   • Arrow Scale: 1.0                                           │
│                                                                 │
│ STEP 4 - Classification                                        │
│   • Movement Threshold: 5.0 pixels                             │
│     └─ Increase for faster cells (7-10)                       │
│     └─ Decrease for subtle movement (2-3)                     │
│                                                                 │
│ STEP 5 - Sampling                                              │
│   • Method: "displacement" (recommended)                       │
│   • Displacement Threshold: 5.0                                │
│   • Number of Samples: 10                                      │
│                                                                 │
└────────────────────────────────────────────────────────────────┘

┌─ VISUALIZATION MODES ──────────────────────────────────────────┐
│ • Overview       → Image, mask, edge overlay                   │
│ • Edge Detection → Edges on image and mask                     │
│ • Displacement   → Displacement maps + statistics              │
│ • Classification → Movement type (extruding/retracting/stable) │
│ • Sampling       → Sampling rectangle locations                │
│ • Intensity      → PIEZO1 intensity values                     │
│ • Correlation    → Intensity vs movement correlation           │
└────────────────────────────────────────────────────────────────┘

┌─ NAVIGATION ───────────────────────────────────────────────────┐
│ ◄◄  First frame     ◄  Previous frame                         │
│ ►   Next frame      ►►  Last frame                            │
└────────────────────────────────────────────────────────────────┘

┌─ MOVEMENT CLASSIFICATION ──────────────────────────────────────┐
│ EXTRUDING  → Edge moving UP/OUT (negative displacement) [BLUE] │
│ RETRACTING → Edge moving DOWN/IN (positive displacement) [RED] │
│ STABLE     → Minimal edge movement [GRAY]                      │
└────────────────────────────────────────────────────────────────┘

┌─ OUTPUT FILES ─────────────────────────────────────────────────┐
│ analysis_results/                                              │
│ ├── step1_results/                                             │
│ │   ├── images.npy            (preprocessed images)           │
│ │   ├── masks.npy             (binary masks)                  │
│ │   └── verification_figures/ (QC plots)                      │
│ ├── step2_results/                                             │
│ │   ├── edges.pkl             (edge coordinates)              │
│ │   └── verification_figures/                                 │
│ ├── step3_results/                                             │
│ │   ├── displacement_data.pkl (displacement maps)             │
│ │   └── verification_figures/                                 │
│ └── ... (continues for all 9 steps)                           │
└────────────────────────────────────────────────────────────────┘

┌─ TROUBLESHOOTING ──────────────────────────────────────────────┐
│                                                                 │
│ GUI won't start:                                               │
│ └─ Check Python version: python3 --version (need 3.6+)       │
│ └─ Install dependencies: pip install -r requirements.txt      │
│ └─ Linux: sudo apt-get install python3-tk                     │
│                                                                 │
│ Analysis fails:                                                │
│ └─ Check Analysis Log for details                            │
│ └─ Verify TIFF files are valid                               │
│ └─ Ensure masks match image dimensions                        │
│ └─ Try running steps individually                             │
│                                                                 │
│ "No valid displacements":                                      │
│ └─ Check edge detection quality                               │
│ └─ Increase smoothing sigma (30-40)                          │
│ └─ Verify mask quality                                        │
│                                                                 │
│ Poor edge detection:                                           │
│ └─ Adjust smoothing sigma                                     │
│ └─ Check background subtraction                               │
│ └─ Review step1 verification figures                          │
│                                                                 │
└────────────────────────────────────────────────────────────────┘

┌─ TIPS ─────────────────────────────────────────────────────────┐
│ • Always review verification figures for quality control       │
│ • Monitor Analysis Log during execution                        │
│ • Use defaults first, then optimize parameters                │
│ • Save different parameter sets for different datasets        │
│ • Each step creates verification_figures/ subdirectory         │
└────────────────────────────────────────────────────────────────┘

┌─ COMMAND-LINE ALTERNATIVE ─────────────────────────────────────┐
│ python run_all_steps.py                    (run all steps)     │
│ python step1_data_loading.py --help        (see options)       │
└────────────────────────────────────────────────────────────────┘

┌─ RECOMMENDED IMAGE SPECS ──────────────────────────────────────┐
│ • Format: Multi-frame TIFF                                     │
│ • Bit depth: 8-bit or 16-bit grayscale                        │
│ • Size: 256x256 to 2048x2048 pixels typical                  │
│ • Frames: Image and mask stacks must match                    │
└────────────────────────────────────────────────────────────────┘

┌─ MEMORY & PERFORMANCE ─────────────────────────────────────────┐
│ • Analysis runs in background thread (GUI stays responsive)    │
│ • Memory usage scales with image size × number of frames      │
│ • Steps 1-4: Fast (seconds to minutes)                        │
│ • Steps 5-9: Slower (minutes, depends on sampling)            │
│ • Monitor progress in Analysis Log                            │
└────────────────────────────────────────────────────────────────┘
